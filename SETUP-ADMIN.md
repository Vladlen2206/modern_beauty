# Клиентская база салона «Модерн» — подключение

Админ-панель открывается по адресу **https://modern-beauty.com.ua/admin/**.
На самом сайте ссылки на неё нет, и поисковики её не индексируют.

## 1. Создать базу в Supabase (бесплатно)

1. Зарегистрируйтесь на https://supabase.com и нажмите **New project**.
   - Region: **Central EU (Frankfurt)** — ближе всего к Украине.
   - Database password: придумайте и сохраните (для панели он не нужен).
2. Откройте **SQL Editor → New query**, вставьте всё содержимое файла
   `supabase/schema.sql` и нажмите **Run**. Должно появиться «Success».

## 2. Запретить самостоятельную регистрацию

**Authentication → Sign In / Providers → Email**: выключите **Allow new users to sign up**.
Тогда новых работников сможет добавить только администратор.

## 3. Создать себя администратором

1. **Authentication → Users → Add user → Create new user**: ваш email и пароль,
   галочка **Auto Confirm User**.
2. **SQL Editor**, выполните (подставьте свой email):

   ```sql
   update public.profiles set role = 'admin', full_name = 'Влад'
   where email = 'ваш@email.com';
   ```

## 4. Подключить панель к базе

**Project Settings → API**: скопируйте **Project URL** и ключ **anon public**
и впишите их в `admin/config.js`. Ключ anon можно хранить в открытом виде:
данные защищает сама база, без входа никто ничего не увидит.

Затем отправьте изменения на GitHub. Vercel сам обновит сайт.

## 5. Добавить мастеров

Для каждого мастера: **Authentication → Users → Add user** (email, пароль,
Auto Confirm). Потом в панели, во вкладке **Майстри**, впишите имя.

## Кто что видит

| | Администратор | Мастер |
|---|---|---|
| Клиенты | все | свои: он их добавил, он их любимый мастер, или у клиента был визит к нему |
| Визиты | все | только свои |
| Статистика | по всему салону и по мастерам | только своя |
| Удалить клиента | да | нет |
| Мастера и услуги | редактирует | нет доступа |

Если мастер вводит телефон клиента, который уже есть в базе у другого мастера,
панель это покажет и предложит добавить визит, не создавая дубль.

Если мастер уволился, снимите галочку «має доступ» во вкладке **Майстри**.
Его визиты останутся в статистике.

## Резервная копия

Бесплатный тариф Supabase не делает автоматических копий. Раз в месяц
скачивайте данные: **Table Editor → clients / visits → Export → CSV**.
